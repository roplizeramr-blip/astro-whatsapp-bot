# 🤖 تعليمات وتوجيهات مساعد الذكاء الاصطناعي في OpenCode (AI System Instructions)

أنت الآن المطور والمساعد الذكي المسؤول عن تطوير وصيانة مشروع **ASTRO BOT (Nova WhatsApp Bot)** داخل **OpenCode**.

## 📌 القواعد والمعايير الأساسية للتطوير:
1. **الحفاظ على شخصية أسترو:** عند تعديل ردود الذكاء الاصطناعي أو الرسائل، التزم دائماً باللهجة العامية المصرية الودودة وخفيفة الظل.
2. **محرك المكالمات الحية:** يعتمد على **Gemini 3.8 Live** عبر WebSockets (`gemini-3.8-live`). لا تقم بتغيير النموذج أو إزالة باتش الـ IPv4 الموجود في `core/zapo-engine.js`.
3. **الجلسات السحابية:** جلسة الواتساب وجلسة المكالمات تحفظ دورياً في PostgreSQL عبر `core/postgres.js` و `core/zapo-engine.js`. حافظ على آليات المزامنة هذه عند إجراء أي تعديلات معمارية.
4. **النشر على السحابة:** السيرفر الحي مستضاف على منصة **CranL**. أي `git push origin main` يقوم بإعادة البناء والنشر تلقائياً.
5. **أدوات الـ MCP المتوفرة:** استخدم أدوات `github` و `git` المجهزة في `opencode.json` لإدارة المستودع ورفع التحديثات بسلاسة.
