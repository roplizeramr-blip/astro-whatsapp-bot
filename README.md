# ASTRO BOT / NOVA ⚡ — بوت واتساب المتكامل والذكي

بوت واتساب مصري ذكي ومحترف مبني على **@rexxhayanasi/elaina-baileys** + **Groq Qwen 3.8 / Luna AI** + **yt-dlp** — ألعاب تفاعلية، ذكاء اصطناعي بذاكرة حقيقية، تحميل وسائط متعدد، إدارة وحماية المجموعات باحترافية.

---

## 🧠 العقل والرد الذكي (AI & Persona)
- **في الخاص:** أي رسالة عادية → يرد استرو فوراً بصوت أو كتابة بأسلوب مصري رايق.
- **في الجروب:** منشن `@البوت` أو رد على رسالته أو اكتب كلمة سحرية («استرو»، «نوفا»، «يا بوت»، «astro»، «nova»).
- **شخصية مصرية حقيقية ابن بلد:** فاهم وذكي، يتفاعل مع المشاعر والمزاج، بدون أي ردود روبوتية أو عبارات ذكاء اصطناعي مصطنعة.
- **ذاكرة مستمرة بالـ LID:** هوية موحدة لكل شخص مهما تعددت أجهزته.
- **تحليل الرسايل الصوتية والصور:** يفهم التسجيلات بـ Whisper ويفهم الصور المرسلة بالذكاء الاصطناعي ويناقشها معك.

## ⚡ أقسام الأوامر الرئيسية (11 قسماً)

### 🤖 1. الذكاء الاصطناعي (`.menu ai`)
* `.ai <سؤال>`: دردشة ذكية مع استرو في أي موضوع.
* `.فكر <معلومة>`: حفظ معلومة أو ذكرى شخصية في ذاكرة استرو الدائمة.
* `.ذاكرتي`: استعراض كل ما يتذكره استرو عنك مع إمكانية حذف أي ذكرى.
* `.image <وصف>`: توليد صور بالذكاء الاصطناعي بجودة عالية.
* `.video <وصف>`: إنشاء فيديو قصير بالذكاء الاصطناعي.
* `.simsimi <كلام>`: كلام وهزار عشوائي.

### 🎮 2. الألعاب والمسابقات (`.menu games`)
* `.quiz`: كويز وتحدي معلومات ضخم (أكثر من 50 سؤالاً ثقافياً وعلمياً وتاريخياً) مع خيارات وأزرار تفاعلية.
* `.guesswho`: لعبة "من هو؟" (تخمين شخصيات تاريخية وعلمية وثقافية ورياضية مشهورة من تلميحات ذكية).
* `.hang`: الكلمة المخفية والمشنقة (تخمين حروف الكلمات مع دعم كامل للغة العربية والتاء المربوطة).
* `.xo`: إكس-أو ضد البوت بذكاء اصطناعي مع رقعة أزرار تفاعلية.
* `.duel @شخص`: مبارزة إكس-أو حقيقية بين عضوين في الجروب مع رهان عملات.
* `.guess`: تخمين الرقم المخفي بين 1 و 50 مع تلميحات وتتبع للمحاولات.
* `.math`: تحدي رياضيات سريع لحساب العمليات الحسابية.
* `.rps`: حجر ورقة مقص ضد البوت بالأزرار.
* `.td`: حقيقة وجرأة (Truth or Dare) بأسئلة وتحديات مصرية مرحة.
* `.coinflip`: ملك أو كتابة برهان العملات.
* `.race`: سباق الحيوانات الممتع في الشات.

### 📥 3. التحميل والميديا (`.menu download`)
* `.song <اسم الأغنية>`: بحث في يوتيوب وتحميل الأغنية بصيغة صوت نقية.
* `.video <اسم الفيديو>`: تحميل فيديو يوتيوب بجودة 360 أو 720.
* `.spotify <اسم الأغنية>`: بحث رسمي في سبوتيفاي مع كارت الغلاف وزر التحميل الفوري.
* `.tiktok <رابط>`: تحميل فيديوهات تيك توك بدون علامة مائية مع نظام احتياطي تلقائي.
* `.ttsearch <موضوع>`: بحث مقاطع تيك توك الرائجة وتنزيلها بدون علامة مائية.
* `.fb <رابط>`: تحميل فيديوهات وريلز فيسبوك العامة بجودة عالية عبر محرك `yt-dlp`.
* `.mediafire <رابط>`: فك وتنزيل روابط ميديافاير وإرسال الملف مباشرة.

### 💰 4. الاقتصاد والرتب (`.menu economy`)
* `.daily`: المكافأة اليومية من العملات.
* `.bank`: إدارة حسابك المصرفي وسحب وإيداع العملات.
* `.transfer @شخص <مبلغ>`: تحويل عملات بين الأعضاء.
* `.shop`: متجر البوت لشراء ألقاب وتلميحات وإلغاء الإنذارات.
* `.slot`: ماكينة الحظ والمراهنة.
* `.rank`: عرض رتبتك وبطاقة خبرتك (XP) ومستواك.
* `.top`: المتصدرين والأغنى في البوت.

### 🛠️ 5. الأدوات والوسائط (`.menu tools`)
* `.run <كود>`: تشغيل كود جافاسكربت وحسابات رياضية متقدمة عبر مشغل الأكواد السريع.
* `.sticker`: تحويل أي صورة أو فيديو قصير إلى ملصق واتساب متحرك أو ثابت.
* `.translate <نص>`: ترجمة فورية بين اللغات مع كشف تلقائي للغة الأصلية.
* `.removebg`: تفريغ وحذف خلفية الصور تلقائياً.
* `.say <نص>`: تحويل النص إلى رسالة صوتية ناطقة.
* `.reminder <وقت> <نص>`: ضبط منبه وتذكير ذكي في الشات.
* `.pin <بحث>`: البحث عن صور Pinterest بجودة فائقة.
* `.gif <بحث>`: البحث عن صور متحركة GIF ومشاركتها كفيديو خفيف.
* `.lyrics <اسم الأغنية>`: استخراج كلمات الأغاني العربية والأجنبية.

### 🎧 6. الموسيقى والمحتوى (`.menu music`)
* `.shazam`: التعرف التلقائي على اسم الأغنية والمطرب بالرد على أي مقطع صوتي.
* `.vocal`: عزل وفصل صوت المطرب عن الموسيقى.
* `.manga <اسم>`: بحث ومعلومات المانجا والمانهوا المصورة.
* `.novel <اسم>`: استكشاف وقراءة روايات Wattpad.

### 😂 7. فرفشة وهزار (`.menu fun`)
* `.joke`: نكت مصرية خفيفة الدم ومواقف كوميدية.
* `.hookah`: قعدة الشيشة والمعسل المصرية الافتراضية مع البوت.

### 🚫 8. الحماية المتقدمة (`.menu protection`)
* مانع الروابط (Anti-link) مع دعم قائمة السماح.
* مانع السبام والفلود (Anti-flood & Anti-spam).
* مانع الشتائم والكلام البذيء (Anti-badwords) وقائمة الحظر المخصصة.
* فحص الصور الإباحية والغير لائقة تلقائياً (NSFW Filter).
* نظام الإنذارات التلقائي (3 إنذارات = طرد فوري).
* `.warn @شخص`: إنذار يدوي مع أزرار سريعة للحظر والكتم.
* `.warns`: كشف سجل الإنذارات الكامل في الجروب مع المنشن المباشر.
* `.ban` و `.unban` و `.mute` و `.unmute`: تحكم شامل في أعضاء الجروب.

### 🛡️ 9. إدارة المجموعات (`.menu group`)
* `.gsettings`: لوحة تحكم تفاعلية بأزرار لتشغيل أو إيقاف كل حماية.
* `.welcome`: رسالة ترحيب مخصصة للأعضاء الجدد (`{user}` و `{group}`).
* `.goodbye`: رسالة وداع عند مغادرة أو طرد أي عضو.
* `.kick @شخص`: طرد فوري.
* `.promote @شخص` و `.demote @شخص`: ترقية وتنزيل المشرفين.
* `.tagall` و `.hidetag`: منشن جماعي للأعضاء والمشرفين.

### 📌 10. أوامر عامة (`.menu general`)
* `.menu`: القائمة التفاعلية الهرمية بـ 3 مستويات.
* `.لغتي`: تحديد لغة وأسلوب استرو (مصري / فصحى / English / فرانكو).
* `.ping`: فحص سرعة الاستجابة واستقرار الخادم.
* `.about`: معلومات وإصدار ومميزات البوت.
* `.report <بلاغ>`: إرسال بلاغ فوري لمالك البوت.

### 👑 11. أوامر المالك (`.menu owner`)
* `.broadcast <رسالة>`: إذاعة رسالة لجميع الجروبات والمحادثات.
* `.boton` و `.botoff`: تشغيل أو إيقاف البوت في شات محدد.
* `.grouplist`: قائمة كل المجموعات المشترك فيها البوت وإحصائياتها.
* `.stats`: لوحة إحصائيات حية للأداء واستهلاك الموارد والأخطاء.

## 🚀 التشغيل والصيانة

```bash
# التشغيل بأمر واحد — البوت الرايسي + سيرفر المكالمات مع بعض
node start.js

# تشغيل خدمة وحدة فقط
node start.js bot     # البوت الرايسي  → :8080
node start.js voip    # المكالمات       → :8090

# التشغيل في وضع المطور (البوت الرايسي فقط)
npm run dev

# التشغيل الدائم عبر PM2 (جوج خدمات)
pm2 start ecosystem.config.cjs
pm2 logs            # لوج الجوج
```

> ⚠️ **Node ≥ 20** ضروري. `node_modules` ديال البوت ما كيحتاجش بناء native
> (حيدنا `better-sqlite3` و `@roamhq/wrtc` وما بقاوش peer مطلوبين).

## 📞 مكالمات صوتية حقيقية (Gemini Live)

بجوج خدمات **مستقلتين** على نفس الحساب:

| | البورت | الجلسة | الدور |
|---|---|---|---|
| 🤖 البوت الرايسي | 8080 (عام) | `session/` | رسائل + أوامر · **مراقب المكالمات فقط** |
| 📞 سيرفر المكالمات | 8090 (داخلي) | `voip-server/session/` | يجاوب على النداء · Gemini Live |

البوت الرايسي **ما كيتدخلش** فـ المكالمات (`core/call-observer.js` read-only) — سيرفر
المكالمات هو اللي كيرد.

**لوحة المكالمات على نفس الدومين** — بلا بورث زايد، البوت كيدير reverse proxy:

```
https://nova-bot-x3unfm.cranl.net/voip   →   http://127.0.0.1:8090/
```

التفاصيل الكاملة: [`voip-server/README.md`](voip-server/README.md).

## 🔐 المتغيرات المطلوبة

كل المفاتيح كتجي من `.env` ولا من متغيرات البيئة ديال المنصة — **حا واحد فـ الكود**:

```bash
GEMINI_API_KEY=...          # مطلوب للمكالمات الصوتية
GROQ_API_KEYS=gsk_..,gsk_.. # مفاتيح الذكاء، مفصولين بفاصلة
```

انسخ `.env.example` إلى `.env` وعمّرها. **ما تحطش أي مفتاح فـ `config.js`** — الملف
tracked وكيترفع للـ GitHub.
